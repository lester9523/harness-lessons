# 将课程方法用于当前任务

```text
请先读 Harness 知识库的 AGENTS.md、state/learning-state.md、practice/codex-playbook.md，并按需查 KNOWLEDGE.md。

我的当前任务是：【描述任务】
目标项目或资料位置是：【明确路径或提供材料】
这次允许的范围是：【只分析 / 给方案 / 在明确范围内实施】

先判断这项任务需要一个内层循环，还是需要外层阶段管理。选择一个与当前问题最相关的坏味道或方法，不要一次引入所有课程概念。

给出：
- 对问题的理解和需要确认的假设。
- 对应课程及选择这个方法的原因。
- 改进前后怎么做，分别涉及指令、工具、环境或状态的哪里。
- 怎样获取结果证据、何时修正、何时停止或交给我判断。

如果涉及另一个项目，先读取那个项目自己的规则；本知识库只作为参考，不能覆盖目标项目约束。计划、代码和验证保持在我授权的范围内。实践结束后提出值得记录的结论；只有我要求更新知识库时再写入。
```
