# 换电脑或新会话接续

将下面的提示词粘贴到以此仓库为工作目录的 Codex 会话中。提示词本身不依赖以前的聊天。

```text
请把当前仓库当作我的 Harness 课程个人知识库，按 AGENTS.md 工作。

先读取 README.md、knowledge/README.md、state/learning-state.md，再按需读取对应方法和 practice/codex-playbook.md，不要一开始加载全部材料。日常解释与应用使用我们自己的方法；需要溯源、处理冲突或核实变化时再查 KNOWLEDGE.md、来源索引和原课。

先给我一份简短接续说明：
1. 目前知识实际覆盖哪些课程，来源最后核对到哪天。
2. 我目前关注什么，哪些只是讨论过、哪些仍待验证。
3. 用通俗语言解释核心概念及其关系，特别区分内外部 Harness 与内外层循环。
4. 建议一个适合今天继续探索的小问题。

然后从我个人的日常工作和软件开发出发，选一个最相关的方法，完整解释什么时候用、具体操作、怎样验收、遇到例外怎么调整。展示一个小任务的改进前后，不要只让我回课程找答案。默认先不写 Java 案例，也不展开团队分享。

引用仓库文件及对应章节，区分课程观点、个人理解与应用建议。不要假设我已掌握全部课程；没有证据时不要声称实践成功。不要自动安装技能或修改其他项目、全局配置。
```
