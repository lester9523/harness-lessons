# Harness 课程个人知识库

用于持续整理《Agent 驾驭工程之美》的课程知识，把理解转化为日常工作方法，并在实践成熟后用于 AI 使用分享。

**日常使用从 [knowledge/README.md](knowledge/README.md) 进入。** 这里把已经整理的课程知识消化成我们自己的工作方法，可以直接判断问题、选择操作并验证结果，无需先回看课程。

[KNOWLEDGE.md](KNOWLEDGE.md) 保留课程整理与来源索引，供复习和溯源。本仓库独立于任何聊天历史：换电脑、换会话后，读取仓库即可接续。

## 在公司电脑接续

第一次拉取：

```zsh
git clone https://github.com/lester9523/harness-lessons.git
cd harness-lessons
```

已有本地仓库：先用 `git status` 检查未提交改动；工作区干净后运行 `git pull --ff-only`。

用 Codex 打开这个目录，粘贴：

```text
请按本仓库 AGENTS.md 工作。先读 knowledge/README.md 和 state/learning-state.md，再按我的问题读取对应方法。优先用我们已经消化的知识解释什么时候用、具体怎么做、怎样验收，给出一个小规模改进方案。日常使用不必先回看课程，只有需要溯源或核实变化时再查 KNOWLEDGE.md 与来源。区分可用方法和已验证经验，不要假设我已经掌握全部内容，也不要自动改我的其他项目或全局配置。
```

更完整的接续方式见 [prompts/resume.md](prompts/resume.md)。不要求安装专用插件或特定 Skill；普通文件即可承载知识。

## 如何持续积累

1. 新课先登记来源、标题、核实日期和实际可读范围。
2. 提炼关键方法，并与已有概念比较；更新课程整理后，再判断 `knowledge/` 的操作方法是否需要补充或修订。
3. 个人推论与实际验证分别记录；实践只在有结果后标记“已验证”。
4. 更新学习状态和变更记录，检查链接后提交。

本仓库只提供知识与方法。将方法用于其他项目时，应明确目标项目和改动范围，再遵循那个项目的规则。

## 检查知识库

本地安装 Python 3 后运行：

```zsh
python3 scripts/check_knowledge.py
```

检查会核对课程记录、原文入口、笔记锚点、本地链接及课程到方法库的覆盖关系。它不能代替对知识准确性和实践有效性的人工核实。

## 来源与使用边界

课程版权属于原作者及平台。仓库保存自主整理的学习笔记和应用方法，以独立理解和使用为目标，重要概念保留原课入口用于溯源；不收录原课程全文。工具操作存在版本差异，使用前根据官方文档核对。
